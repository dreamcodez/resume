## Yew App Development

- **Start the dev server (shows all errors, hot reloads):**

  ```sh
  cd yew
  trunk serve
  ```

- **Build for production:**

  ```sh
  cd yew
  trunk build --release
  ```

- **Check Rust code only (fastest feedback):**

  ```sh
  cd yew
  cargo check
  ```

If you see repeated "Rebuilding..." or a hang, check the terminal for the first error message.

---

## Other Notes

- Use Trunk directly for all Yew web work.
- Use `cargo check` for Rust-only.
- Minimize scripts—just document the commands in your README.
- All errors will always be visible in the terminal.
